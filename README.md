# CineTrack 

## Fonctionnalités

### Page principale
- Afficher la liste des films et des séries.
- Rechercher un film ou une série par son titre.
- Filtrer les contenus par type (film ou série).
- Afficher les détails d'un contenu dans une fenêtre (modal).
- Ajouter des films et des séries aux favoris.
- Supprimer des contenus de la liste des favoris.
- Naviguer entre les pages avec la pagination.

### Page Admin

- Ajouter un nouveau film ou une nouvelle série.
- Afficher les contenus existants.
- Modifier les informations d'un contenu.
- Supprimer un contenu.

## Technologies utilisées

- HTML : structure des pages.
- CSS : mise en forme.
- Tailwind CSS : design de l'application.
- JavaScript : fonctionnalités et interactions.
- MockAPI : stockage et gestion des données.
- Fetch API : communication avec l'API.
- LocalStorage : sauvegarde des favoris dans le navigateur.
